## コンセプト：「推し俳優」文化を作る

### 背景・課題
- アイドルやミュージシャンには「推し活」文化が定着しているが、**俳優にはほとんど見られない**
- 舞台俳優は「会場に行けば本人に会える」という最大の魅力があるのに、それが十分に活用されていない

### 解決アプローチ
- キャスト11名の**ポップ・カワイイ系アニメキャラクター（アバター）**を制作
- **AI動画生成ツール（Kling / Runway）**でキャラ動画を量産し、SNSで展開
- アニメキャラで「推し」を作る → 「本物に会いたい！」→ 会場へ → グッズも欲しくなる導線

### ファン導線設計
```
アニメキャラ動画でキャストの魅力を知る
  ↓
推しキャラ（＝推し俳優）ができる
  ↓
「本物に会いたい！」→ チケット購入
  ↓
会場で本人に会える感動・ワクワク
  ↓
推しグッズが欲しくなる（アクスタ・缶バッジ等）
  ↓
SNSでシェア → 新規ファン獲得の循環
```
